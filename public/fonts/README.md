LXGW WenKai TC (霞鶩文楷 TC) v1.522

Source: https://github.com/lxgw/LxgwWenkaiTC/tree/v1.522/fonts/TTF
Source file: LXGWWenKaiTC-Regular.ttf
Source SHA-256: b1a0795862c1415bf3f393ea50b2a4ea6275012cf5bad3f94feeb1222f555731

PlayStatsTC-Regular.woff2 is a WOFF2 subset covering the website's source text and printable ASCII. The glyph designs are unchanged. The subset's internal family name is PlayStats TC, following upstream's request to avoid its brand names for derived fonts. Distributed under SIL OFL 1.1; see LXGWWenKaiTC-OFL.txt. The original copyright and licensing records are preserved in the font.

Traditional Chinese pages and the Traditional Chinese language option use this font. It is self-hosted and not preloaded on other languages. Simplified Chinese and English keep Smiley Sans.

After adding website text, regenerate the subset with Python fonttools 4.61.1 and brotli 1.2.0 installed:

    python scripts/subset-traditional-font.py /path/to/LXGWWenKaiTC-Regular.ttf

Use the versioned official source above and verify its SHA-256 before regeneration.
